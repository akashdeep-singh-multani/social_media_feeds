## Getting Started

1. **Fork the repository**: Click the "Fork" button in the top right corner of this page.
2. **Clone your fork**: Use the command below to clone your fork to your local machine.
```bash
git clone https://github.com/akashdeep-singh-multani/social_media_feeds.git
cd social_media_feeds
```
3. ***Install dependencies**:
    npm install
4. **Run the application**
    npm start


## Reporting Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository. When reporting an issue, please include:

1. A descriptive title
2. Steps to reproduce the issue
3. Any error messages you received
4. Your operating system and version
5. The version of the project you're using


## Submitting Changes

1. Create a new branch:
git checkout -b feature/your-feature-name
2. Make your changes: Write your code and add necessary tests.
3. Commit your changes: Write a clear commit message
git commit -m "Add a feature that does X"
4. Push your changes:
git push origin feature/your-feature-name
5. Create a Pull Request: Go to the original repository and click on the "New Pull Request" button. Make sure to describe your changes and why they should be merged.
